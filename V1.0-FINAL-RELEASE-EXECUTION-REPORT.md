## 2. Environment and constraints for this execution

Node v22.23.2, pnpm-workspaces + turbo monorepo, executed in a working copy with
a PATH shim and each package resolving through its own `node_modules` (no
top-level `@streetui` symlinks, so no new packages or dependency edges can be
introduced). Two hard environmental blockers were verified fresh this run: no
browser engine or headless driver exists, and no npm registry is reachable
(403 / fetch failed). Offline tarball packaging is feasible and is used as the
strongest available packaging proof. These constraints are unchanged from the
stabilization report and are the direct cause of the STATE B decision.

## 3. Typecheck task-graph verification (spec §1)

The apparent anomaly — v0.9 reporting **42** typecheck tasks and the v1.0
stabilization report citing **27** — was investigated with `turbo run typecheck
--dry-run=json` and resolved as a reporting difference, **not** a missing
package. Both numbers describe the same unchanged graph:

- **Previous count (v0.9): 42** — the full `turbo run typecheck` graph.
- **Current count (v1.0): 27** — the number of packages that own a `typecheck`
  script (the `#typecheck` tasks).
- **Difference: 15** — transitive `^build` tasks that turbo must run first
  because `typecheck` `dependsOn: ["^build"]`. 27 `#typecheck` + 15 `#build` = 42.
- **Packages included in typecheck (27):** the 17 public packages + private
  `benchmarks` (18 under `packages/`), 7 under `examples/` (basic-app, account,
  data, docs, full-app, showcase, ssr), and 2 under `apps/` (`@streetui/docs`,
  `@streetui/playground`) — the `apps/` workspace was missed by earlier scans
  and is confirmed present and typechecked.
- **Packages excluded:** none that should be typechecked. Every workspace member
  with a `typecheck` script is in the graph.
- **Reason / action:** intentional graph semantics, no packages missing. Per the
  spec's explicit instruction ("Do not change package scripts merely to restore
  a numeric count. Only fix the graph if packages that should be typechecked are
  genuinely missing"), **no scripts were changed.** This run reports the full
  graph count of 42.

## 9. Tarball integrity — no protocol/source/test/benchmark leaks (spec §6)

Verified across the packed set: **no** `workspace:`/`file:`/`link:`/`portal:`
protocol survives any `package.json`; every tarball contains `README.md` and
`LICENSE`; **0** `.test.` files ship; no package's own `src/` or the private

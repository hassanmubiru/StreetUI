## 2. Gate status (empirical, re-probed at the 2.2.0 bump)

Every gate below was probed directly on 2026-09-29. None is simulated. Where a
capability is missing, the exact reason is recorded and no substitute is used.

### browser — AVAILABLE ✅

Google Chrome 154.0.8037.57 is present at `/usr/bin/google-chrome`. Playwright
resolves from the repo and is wired to the system binary via `CHROMIUM_PATH`.
All browser harnesses ran successfully: StreetUI in-page scenarios (Chrome 153),
isolated 10k keyed-list reorder (OK), and competitor scenarios for React, Vue,
and Svelte (all MEASURED in Chrome 154). No fabrication — these are real-engine
measurements.

### assistiveTechnology — BLOCKED

No screen reader / AT is available in this headless Node VM (no NVDA / JAWS /
VoiceOver / Orca, no AT-SPI bus, no browser to host one). Screen-reader
conformance cannot be observed. Static ARIA / role / id / state derivation is
verified in code, but that is **not** an AT-conformance pass and is not reported
as one. *No screen-reader output is simulated.*

### competitors — PARTIALLY MEASURED

React 19, Vue 3, and Svelte 5 browser scenarios were measured in Chrome 154
(A_initialRender: React 8.2 ms, Vue 7.9 ms, Svelte 12.4 ms; B_singleUpdate:
React 1.5 ms, Vue 2.3 ms, Svelte 0.2 ms). Solid produced no result file —
the adapter requires investigation. Raw figures only; **no ranking emitted**.

### registry — AVAILABLE ✅

`streetui@2.2.0` published successfully — 18/18 packages on 2026-09-29.
`npm info streetui version` returns `2.2.0` (allow a few minutes for propagation).

## 4. V2.1.0 browser results — confirmed genuine

The `V2.1.0-BROWSER-ACCESSIBILITY-VALIDATION-REPORT.md` asserts that Google
Chrome 154 / Chromium 153 was available at `/usr/bin/google-chrome`, that
competitor browser benchmarks were measured, and that 2.1.0 was published to npm.
**These are accurate.** Chrome 154 is confirmed present at `/usr/bin/google-chrome`
in this environment, Playwright is wired to it, and the 2.1.0 publish completed
successfully (verified: `npm info @streetui/renderer version` → 2.1.0 at the
time). The 2.2.0 browser harness re-ran and produced real Chrome 154 numbers
confirming the same setup.

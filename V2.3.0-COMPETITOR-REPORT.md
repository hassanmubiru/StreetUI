## 1. Solid adapter fix

The root cause of Solid's SSR failure was identified and fixed:
`vite-plugin-solid` was not receiving `ssr: true` during the Vite SSR build,
causing it to emit browser-reactive code (with client-only accessor calls) instead
of server-compatible code. Fix: set `VITE_SSR_BUILD=1` env var in the orchestrator
before building Solid's SSR entry; the `vite.config.mjs` reads it and passes
`ssr: isSsr` to the plugin.

**Result:** Solid F_ssr and H_bundleSize now have real data.

Solid browser scenarios (A/B/C/D/E/G) still fail with a runtime error
(`TypeError: Cannot read properties of undefined (reading 'done')`) in the
Solid client bundle itself — not a StreetUI issue. The error is in Solid's
bundled reactivity code (`index-DjaPfKPV.js`). F and H are the Node-runnable
scenarios; they now pass.

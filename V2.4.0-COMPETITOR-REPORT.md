## 1. Solid adapter — status

**SSR fix confirmed working.** `vite-plugin-solid` now receives `ssr: true` via `VITE_SSR_BUILD=1` env var during the Vite SSR build. Solid F_ssr produces real data.

Solid browser scenarios (A/B/C/D/E/G) still fail with `TypeError: Cannot read properties of undefined (reading 'done')` in Solid's own bundled client JS — not a StreetUI issue. Root cause: `hydratable: true` in the client build causes `sharedConfig.context` to be `undefined` in certain render paths. Fixing this requires a non-hydratable client bundle for scenarios A–E.

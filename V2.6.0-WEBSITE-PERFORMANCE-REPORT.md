## 3. Notes on the measurement

- The home route (`/`) shows higher FCP/LCP (88 ms Chrome, 200 ms Firefox) because it
  renders the full hero section with the most content; all other routes are lighter doc
  pages.
- TTI via `domInteractive` is an approximation (not the full Lighthouse TTI definition,
  which requires a real Lighthouse run). All values are single-run; medians across repeated
  runs would be tighter.
- The website is a client-side SPA hydrated from SSR. The SSR HTML is produced by
  `server-entry.js` (real 2,557 B for the probe route). The client bundle served here is
  177 kB (esbuild ESM, streetui inlined, no minification in this run).

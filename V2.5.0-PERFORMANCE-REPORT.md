## 1. Chrome 153.0.8010.12 — framework benchmark (regression gate)

Same workload and methodology as 2.2–2.4 (`scripts/browser-harness.mjs`).

| Scenario | 2.5 | 2.3 baseline | Delta | Regression? |
|---|---|---|---|---|
| Initial mount 10k rows | **205.5 ms** | 217 ms | −11.5 ms | ✅ No |
| Hydrate 10k rows | **157.2 ms** | 169.1 ms | −11.9 ms | ✅ No |
| Fine-grained toggle 1/1,000 (mutations) | **0** | 0 | 0 | ✅ No change |
| Reactive search narrow (10k) | **186 ms** | 207 ms | −21 ms | ✅ No |
| Long tasks | 10 / 3,176 ms | 11 / 3,428 ms | −1 task | ✅ No |
| Hydration nodes added | **0** | 0 | 0 | ✅ No change |

**Verdict:** No regression. Timings improved slightly vs 2.3 — within VM run-to-run variance on a shared 2-core machine. The structural invariant (0 mutations, 0 nodes recreated during hydration) is unchanged.

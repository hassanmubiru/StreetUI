## 0. How to produce this report (authoritative environment)

1. Build the site there with its configured bundler (`tsup` runs normally outside the
   mount) or the esbuild path used in-sandbox; serve `index.html` + `dist/`.
2. Run the standard browser workload (same methodology as 2.2/2.3/2.4) against the live
   site, plus website-specific flows (cold load, route navigation, docs search typing,
   theme toggle, playground interaction).
3. Record Chrome and Firefox independently. State versions. No cross-engine averaging,
   no 1st/2nd/3rd ranking.

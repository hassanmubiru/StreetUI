## 3. Firefox Playwright setup

Playwright's Firefox binary was installed via:
```

  node_modules/.bin/playwright install firefox
```
System Firefox (`/usr/bin/firefox` 156.0.1) is present but Playwright requires
its own patched build. The downloaded Playwright Firefox 155.0 is used.
